# 常见问题与故障排查

遇到结果缺失或显示异常时，先确认当前计算模式、公式是否填写完整，以及影响结果的设置是否符合预期。本页集中整理跨模块问题，详细操作仍以对应专题教程为准。

## 为什么按下等号没有得到结果？

不同模式使用不同的完成方式：

| 模式 | 完成当前任务的按键或操作 |
| --- | --- |
| 基础计算 | 点击 `=` |
| 科学计算 | 点击 `=` |
| 方程求解 | `=` 只写入等式，点击 `EXE` 才开始求解 |
| 矩阵与向量 | 点击 `=` |
| 函数图像 | 点击“确定”保存表达式，再关闭编辑面板查看图像 |
| 汇率 | 输入金额后实时换算，不需要等号 |

<ThemeImage
  src="/images/docs/equations/overview/equal-and-exe.png"
  alt="方程键盘中的等号用于输入等式而 EXE 用于执行求解"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

如果操作正确仍没有结果，请检查公式中是否还有空白框、括号是否成对，以及分数、根式、指数或函数参数是否填写完整。

## 为什么输入出现在了错误位置？

CalculatorX 会把新内容插入当前光标位置。光标如果仍位于分母、指数、矩阵元素或模板空白框中，后续输入也会进入那里。

可以这样处理：

1. 使用方向键把光标移到目标位置；
2. 点击 <BackspaceKey /> 删除错误内容；
3. 在科学计算、方程和矩阵模式中使用顶栏撤销；
4. 结构已经混乱时，点击 `AC` 清空并重新输入。

基础计算没有独立方向键和顶栏撤销。复杂公式更适合在科学计算模式中输入。

## 为什么结果和预期不同？

依次检查以下条件：

- 是否使用括号明确了运算顺序；
- 三角函数所需的是 `DEG` 还是 `RAD`；
- “答案输出”是自动模式还是小数模式；
- 小数精度是否过低；
- `Ans` 是否确实来自当前计算模块的最近结果；
- 输入是否超出函数定义域，例如除以零、负数开偶次方根或对非正数取实对数。

修改角度单位、答案输出或小数精度后，应重新执行计算。`S⇄D` 只临时转换最近一次结果，不会修改全局答案设置。

## 方程为什么没有求出未知数？

方程模式只把以下六个变量识别为待求未知数：

$$
x,\ y,\ z,\ u,\ v,\ w
$$

检查事项：

- 方程左右两边之间是否输入了 `=`；
- 完整输入后是否点击了 `EXE`；
- 是否误用 $m$、$n$ 等其他字母作为未知数；
- 方程组模板是否有空白行；
- 多元方程组是否提供了足够且不矛盾的等式。

结果显示“无解”可能是输入不完整，也可能表示方程本身确实没有解。高次方程还可能返回多个根或复数根。

详细步骤见[求解单个方程](/equations/overview)和[求解方程组](/equations/systems)。

## 矩阵为什么提示尺寸问题或无法运算？

不同运算的尺寸要求不同：

- 加法、减法和哈达玛积要求两个矩阵同型；
- 矩阵乘法要求左矩阵列数等于右矩阵行数；
- 求逆、行列式、迹、特征值和矩阵乘方要求方阵；
- 求逆还要求方阵可逆；
- 所有矩阵元素都必须填写完整。

如果第二个矩阵被插入到第一个矩阵的某个元素中，说明光标还没有移到矩阵外侧。撤销后，先使用方向键离开当前矩阵再重新插入。

## 为什么函数图像没有显示？

按顺序检查：

1. 是否点击“确定”保存了表达式；
2. 条目左侧圆点是否为彩色可见状态；
3. 是否选择了正确函数类型；
4. 是否使用该类型提供的变量；
5. 参数方程是否同时填写了 $x(t)$ 与 $y(t)$；
6. 参数或极坐标定义域是否覆盖目标范围；
7. 三角函数的 `DEG/RAD` 设置是否正确；
8. 图像是否位于当前视野之外，尝试缩小和平移画布。

<ThemeImage
  src="/images/docs/graphing/manage-functions/visibility.png"

隐函数只输入等于零之前的表达式。例如圆 $x^2+y^2=4$ 应输入 $x^2+y^2-4$。更多排查方法见[观察与调整图像](/graphing/view-graph)。

## 为什么汇率更新失败或结果异常？

没有网络时，CalculatorX 会保留最近成功获取的汇率，但顶部会显示更新失败。首次使用且没有缓存时，必须先联网成功更新一次，否则缺少汇率的货币可能显示异常接近或相同的金额。

<ThemeImage
  src="/images/docs/exchange/rates-and-offline/update-failed.png"
  alt="汇率页面更新失败后显示红色失败提示和重试按钮"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

可以检查：

- 系统是否已经连接到可访问互联网的网络；
- 公共 Wi-Fi 是否需要先完成网页认证；
- 顶部“上次更新”是否为“从未更新”；
- 稍后是否能够通过“重试 ↻”成功更新；
- 同一小时内是否正在复用缓存，而不是重复下载汇率。

汇率会随市场和数据源更新，实际交易价格还可能包含点差或手续费。详细说明见[更新汇率与离线使用](/exchange/rates-and-offline)。

## 为什么找不到历史记录？

CalculatorX 只保存成功计算的表达式和结果。请检查：

- 是否打开了正确模块的局部历史或全局分类；
- 当时的计算是否成功；
- 记录是否曾被左滑删除或整类清空；
- 记录是否已经超过该模块最近 $100$ 条的保留范围。

函数图像通过编辑列表保存，不进入计算历史；汇率通过货币列表和缓存保存，也不进入计算历史。历史删除和清空无法撤销。

详细操作见[查看和复用历史记录](/history)。

## 为什么设置修改后没有影响旧结果？

角度单位、答案输出和小数精度会影响后续计算。已经显示的旧结果不会因为设置变化自动重新计算，应返回计算页面再次点击等号或执行相应操作。

颜色模式和触感反馈会立即应用。触感反馈还依赖 HarmonyOS 系统触感设置；应用内已经开启但按键仍不振动时，应同时检查系统设置。

详细说明见[调整 CalculatorX 设置](/settings)。

## 问题仍未解决

联系维护者时，建议同时提供：

- CalculatorX 版本；
- 设备型号和 HarmonyOS 版本；
- 出现问题的计算模式；
- 能够复现问题的完整输入和操作步骤；
- 预期结果与实际结果；
- 不含通知、账号或其他个人信息的截图。

联系方式和开源仓库入口见[关于 CalculatorX](/about)。
