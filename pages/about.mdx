# 关于 CalculatorX

**CalculatorX** 是一款专为 HarmonyOS 打造的高性能科学计算器。我们致力于在移动设备上提供桌面级的精确计算与符号推导体验。

---

* **开发者：** 易睿 (Yi Rui)

### 特别鸣谢

> "我们站在巨人的肩膀上。"

CalculatorX 的强大不仅源于自身的架构设计，更得益于开源社区的无私奉献。本项目在底层 CAS 引擎、高精度计算以及前端渲染等模块，深度依赖或参考了以下卓越的开源组件与第三方库：

* **[Giac/Xcas](https://www-fourier.univ-grenoble-alpes.fr/~parisse/giac.html)**
  核心微积分与高级符号运算引擎
* **[SymEngine](https://github.com/symengine/symengine)**
  基础计算机代数系统 (CAS)
* **[MathLive](https://cortexjs.io/mathlive/)**
  前端公式渲染与 MathJSON 引擎
* **[nlohmann/json](https://github.com/nlohmann/json)**
  C++ 高效 JSON 解析库
* **[Boost](https://www.boost.org/)**
  高性能泛型 C++ 基础库
* **[GMP](https://gmplib.org/)**
  GNU 多精度算术库，提供极速大数支持

向以上所有开源项目的贡献者致以最诚挚的敬意！
