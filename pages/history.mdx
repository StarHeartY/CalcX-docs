# 查看和复用历史记录

CalculatorX 会在计算成功后保存表达式和结果。你可以从当前模式的局部历史快速回填内容，也可以从侧边栏进入全局历史，跨模式查找和复制过去的计算。

## 打开当前模式的历史

基础计算、科学计算、方程求解和矩阵模式的顶栏右侧会显示历史按钮：

1. 切换到想要查看的计算模式。
2. 点击右上角的历史按钮。
3. 从底部出现的历史面板中浏览记录。

<ThemeImage
  src="/images/docs/history/local-history.png"
  alt="CalculatorX 当前计算模式的局部历史记录面板"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}

局部历史只显示当前模式对应的记录。函数图像模式的右上角是编辑按钮，汇率模式也不使用计算历史。

## 把历史内容插入当前公式

每条局部历史分为上下两个可点击区域：

- 点击上方表达式区域，将原来的输入插入当前光标位置；
- 点击下方结果区域，将计算结果插入当前光标位置。

<ThemeImage
  src="/images/docs/history/insert-from-history.png"
  alt="历史记录中可分别点击表达式区域和结果区域进行回填"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

选择后，局部历史面板会关闭，内容被插入公式显示区。插入前应留意当前光标位置；如果光标位于分母、指数或其他子结构中，历史内容也会插入那里。

局部历史标题旁的问号按钮会显示同样的图文提示。

## 打开全局历史记录

全局历史用于跨模式查看记录：

1. 打开左侧侧边栏。
2. 点击侧边栏顶部的历史记录按钮。
3. 在底部分类栏中切换需要查看的记录范围。

你也可以先打开局部历史，再点击面板右上方的全局历史按钮。

<ThemeImage
  src="/images/docs/history/global-history.png"
  alt="CalculatorX 全局历史记录页面及底部分类栏"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

全局历史中的记录会按今天、昨天或具体日期分组。点击表达式或结果时，CalculatorX 会把对应文本复制到系统剪贴板，并显示“已复制表达式”或“已复制结果”。随后可以在支持文本粘贴的位置继续使用。

局部历史的点击行为是直接回填，全局历史的点击行为是复制到剪贴板，两者不要混淆。

## 删除单条记录

在历史列表中向左滑动一条记录，然后选择删除。删除后该记录无法从应用内恢复。

## 清空一类历史记录

局部历史右上角的垃圾桶会清空当前模式的全部记录。全局历史右上角的垃圾桶会根据当前分类清空对应范围：

1. 先确认当前所在的模式或分类。
2. 点击垃圾桶按钮。
3. 阅读确认对话框中的范围。
4. 确认无误后点击“清空”。

清空操作无法撤销。若只是想移除一两条内容，应优先使用左滑删除。

## 历史记录的保存规则

- 只有成功计算的表达式和结果会进入计算历史；
- 同一模块连续计算完全相同的输入时会自动去重；
- 每个计算模块最多保留最近 $100$ 条记录；
- 历史记录保存在设备本地，不需要联网查看。

## 找不到某条记录时

可以依次检查：

1. 是否打开了正确的计算模式或全局分类；
2. 当时的计算是否成功得到结果；
3. 是否曾经清空该分类；
4. 记录是否已经超过该模块保留的最近 $100$ 条范围。
