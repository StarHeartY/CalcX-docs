# 求解单个方程

方程求解模式把等号输入和开始求解分成了两个按键。你可以先像书写普通公式一样输入完整等式，再点击 `EXE` 求出未知数。

## 进入方程求解

1. 点击左上角的侧边栏按钮。
2. 在“进阶”分组中选择“方程求解”。
3. 检查顶栏中间是否显示“方程求解”。

方程键盘上方提供分数、根式、幂、指数、对数、三角函数、方程组模板和方向键；下方提供数字、四则运算、等号与 `EXE`。

## 可以求解哪些未知数

方程求解会从表达式中识别以下六个未知数：

$$
x,\ y,\ z,\ u,\ v,\ w
$$

其中 $x$、$y$、$z$ 直接显示在高级键盘中。$u$、$v$、$w$ 是它们上方的橙色第二功能：先点击 Shift，再点击对应按键即可输入。

<ThemeImage
  src="/images/docs/equations/variables.png"
  alt="方程求解键盘中的 x、y、z 以及 Shift 第二功能 u、v、w"
  width={1424}
  height={2931}
  style={{ maxWidth: '320px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

使用 $m$、$n$ 等其他字母书写参数时，它们不会被当作待求未知数。需要明确求解某个量时，应使用上述六个变量之一。

## 完成一次一元方程求解

下面求解：

$$
2x+3=11
$$

1. 依次输入 $2$、$x$、$+3$。
2. 点击 <kbd className="key-cap">=</kbd>，在公式中插入等号。
3. 输入等号右侧的 $11$。
4. 检查公式完整无误后，点击 <kbd className="key-cap">EXE</kbd>。
5. 结果应显示 $x=4$。

<ThemeImage
  src="/images/docs/equations/single-equation.png"
  alt="方程求解模式输入二 x 加三等于十一并得到 x 等于四"
  width={1424}
  height={2931}
  style={{ maxWidth: '320px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

数字与变量相邻时表示乘法，因此输入 $2$ 后直接输入 $x$ 即可得到 $2x$，不必额外插入乘号。

## 区分等号与 EXE

| 按键 | 作用 |
| --- | --- |
| `=` | 把等号写入当前公式，分隔方程左右两边 |
| `EXE` | 把已经写好的方程交给 CalculatorX 求解 |

<ThemeImage
  src="/images/docs/equations/equal-and-exe.png"
  alt="方程键盘底部并列显示用于输入等式的等号键和执行求解的 EXE 键"
  width={1424}
  height={2931}
  style={{ maxWidth: '320px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

只点击 `=` 不会开始计算；只输入表达式而没有等式，也无法明确方程的左右两边。通常应先完成“左边 = 右边”，最后再点击 `EXE`。

## 查看多个解

高次方程可能有多个解。例如：

$$
x^2=4
$$

输入方程并点击 `EXE` 后，结果会分别标出 $x$ 的多个根。出现多个结果时，应把它们看作同一个方程的完整解集，而不是只取第一个结果。

<ThemeImage
  src="/images/docs/equations/multiple-roots.png"

方程求解使用复数求解能力，因此某些在实数范围内没有解的方程仍可能返回复数结果。

## 编辑与复用方程

- 使用左右方向键移动到需要修改的位置；
- 使用上下方向键进入分数、根式或指数等多层结构；
- 点击退格删除光标前的内容，长按可以连续删除；
- 使用顶栏的撤销和重做恢复编辑步骤；
- 求解成功后，点击右上角历史按钮可以重新插入旧方程或结果。

如果结果显示无解，应先检查等号是否完整、变量是否属于支持范围，以及方程本身是否确实存在解。
