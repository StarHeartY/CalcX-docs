# 更新汇率与离线使用

汇率模式进入时会先读取设备中保存的货币列表、金额和最近一次汇率，再检查是否需要联网更新。这样即使网络暂时不可用，只要设备中已有缓存，仍可以继续查看换算结果。

## 查看更新时间

页面顶部显示“上次更新”：

- 今天更新的数据显示为“今天 时:分”；
- 更早的数据显示为“月-日 时:分”；
- 从未成功获取数据时显示“从未更新”。

更新时间可以帮助判断数据是否仍适合当前用途，但不能代表银行或交易市场的实际报价时间。

## 手动更新汇率

1. 确认设备已经联网。
2. 点击右上方的“更新 ↻”。
3. 更新期间按钮显示“更新中...”。
4. 成功后页面短暂显示“更新成功”，并刷新顶部时间。

进入汇率模式时也会自动执行同样的检查，通常不需要每次手动点击更新。

## 同一小时内的缓存

CalculatorX 按设备本地时间的自然小时复用汇率缓存。如果最近一次成功更新仍处于当前小时，并且设备确认有网络，点击更新会直接复用缓存，不重复下载完整汇率表。

因此，同一小时内看到“更新成功”表示当前缓存已通过更新检查，不一定代表刚刚重新从服务器下载了数据。跨过整点后，下一次进入页面或手动更新会尝试获取新数据。

## 离线使用

没有网络时：

- 页面保留最近成功获取的汇率；
- 已有缓存的换算仍在设备本地完成；
- 手动更新会显示“更新失败”和网络连接提示；
- 货币列表、排序和输入金额仍可正常修改并保存。

<ThemeImage
  src="/images/docs/exchange/rates-and-offline/offline-cache.png"
  alt="设备离线时汇率页面保留已有换算结果并显示旧的更新时间"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

缓存不会因为更新失败而被清空。离线期间应结合顶部更新时间判断数据是否过旧。

## 首次使用时需要联网

如果设备从未成功下载过汇率，离线状态下没有可靠的汇率表可供换算。此时可能出现不同货币金额异常接近或相同的情况。

首次使用建议：

1. 连接网络；
2. 进入汇率模式；
3. 等待更新成功；
4. 检查顶部不再显示“从未更新”。

完成一次成功更新后，后续才能可靠地使用本地缓存。

## 更新失败时

更新失败后，页面会短暂显示红色“更新失败”，按钮变为“重试 ↻”，并通过提示说明网络或数据问题。

<ThemeImage
  src="/images/docs/exchange/rates-and-offline/update-failed.png"
  alt="汇率更新失败后显示红色失败状态和重试按钮"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

可以依次检查：

1. 系统是否已经连接到可访问互联网的网络；
2. 是否处于需要网页认证的公共 Wi-Fi；
3. 顶部是否仍有可用的历史更新时间；
4. 稍后重新进入页面或点击“重试 ↻”；
5. 某种货币结果异常时，尝试联网更新完整汇率表。

## 数据与隐私

CalculatorX 联网更新时只获取汇率表。输入金额、货币卡片和排序保存在设备本地，换算也在本地完成，不需要把每次输入的金额发送给汇率服务。
