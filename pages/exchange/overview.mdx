# 完成一次汇率换算

汇率模式可以把一个输入金额同时换算成列表中的多种货币。你可以随时点击另一张货币卡片，把它改成新的输入货币，其余结果会自动重新计算。

## 开始换算

### 进入汇率模式

1. 点击左上角的侧边栏按钮。
2. 在“转换”分组中选择“汇率”。
3. 等待页面载入本地数据并检查最新汇率。

<ThemeImage
  src="/images/docs/exchange/overview/overview.png"
  alt="CalculatorX 汇率模式显示更新时间、货币卡片和金额输入键盘"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

首次使用时，默认列表包含美元、人民币、港币、欧元、英镑、日元和韩元，默认输入金额为 $100$。以后再次进入时，会恢复你保存的货币顺序、输入金额和当前输入货币。

### 输入换算金额

当前输入货币的卡片会突出显示，并打开底部数字键盘：

1. 点击目标卡片右侧的货币名称或金额区域。
2. 使用 <kbd className="key-cap">AC</kbd> 清空旧金额。
3. 输入新的整数或小数金额。
4. 列表中的其他货币会同步显示换算结果。
5. 点击 <kbd className="key-cap">确定</kbd> 或键盘收起键，关闭数字键盘。

  src="/images/docs/exchange/overview/amount-input.png"

  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

<ThemeImage
  src="/images/docs/exchange/overview/results.png"
  alt="输入美元金额后人民币、港币、欧元等卡片同步显示换算结果"

换算结果最多保留四位小数，并自动去掉末尾多余的零。汇率会随更新时间变化，因此教程不提供固定的换算数值。

### 使用金额键盘

汇率键盘提供：

- 数字 `0` 至 `9`；
- 小数点；
- `AC` 清零；
- 退格；
- <kbd className="key-cap">确定</kbd> 和键盘收起键。

<ThemeImage
  src="/images/docs/exchange/overview/keyboard.png"
  alt="汇率金额键盘包含数字、小数点、清空、退格、收起和确定按键"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

金额输入有以下限制：

- 最多输入 15 个字符；
- 一个金额只能包含一个小数点；
- 使用 <BackspaceKey /> 删除到最后一位时会恢复为 `0`；
- 当前键盘不提供负号，只用于输入非负金额；
- 手动滚动货币列表时，键盘会自动收起。

### 切换输入货币

点击任意其他货币卡片的名称或金额区域，该卡片会成为新的输入货币。CalculatorX 会先把它当前显示的换算值作为新金额，再重新计算其他卡片，因此切换过程中代表的价值不会突然改变。

<ThemeImage
  src="/images/docs/exchange/overview/switch-base.png"
  alt="从美元卡片切换到人民币卡片作为新的金额输入货币"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

点击卡片左侧的货币代码和下拉箭头是更换该卡片的货币类型，不是切换输入状态。两个点击区域的作用不要混淆。

## 结果仅供参考

页面顶部会显示“上次更新”时间，并注明汇率数据仅供参考。银行、支付平台、现金兑换点或交易市场可能加入点差、手续费和更新时间差异，实际成交金额应以服务提供方报价为准。
