# 管理换算货币

汇率页面的每张卡片代表一个换算目标。你可以从当前支持的 172 种货币或资产中选择条目，并按照自己的使用习惯调整列表顺序。

## 选择货币

### 更换卡片中的货币

1. 点击卡片左侧的货币代码和下拉箭头。
2. 在“选择货币”窗口中找到目标条目。
3. 点击货币后，选择窗口会自动关闭，原卡片改为新的货币。

<ThemeImage
  src="/images/docs/exchange/currencies/currency-selector.png"
  alt="选择货币窗口显示常用分组、字母分组和当前货币勾选状态"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

选择窗口顶部先显示 11 种常用货币，后续按货币代码首字母分组。右侧字母索引可以快速跳转到对应分组，当前卡片中的货币会高亮并显示勾选。

### 搜索货币

在顶部搜索框中可以输入：

- 货币代码，例如 `USD`、`CNY`；
- 中文名称，例如“人民币”“欧元”；
- 英文名称或国家地区；
- 常见简称或别称；
- 货币符号。

<ThemeImage
  src="/images/docs/exchange/currencies/search-currency.png"
  alt="货币选择器搜索人民币并显示代码、名称和货币符号"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

搜索时右侧字母索引会隐藏，底部会显示匹配数量。没有结果时，页面显示“未搜索到任何内容”。

### 支持的条目类型

当前列表共 172 种条目，除了常见法定货币，还包括：

- 比特币 `BTC`；
- 黄金、白银、钯金和铂金等按盎司计价的贵金属；
- 国际货币基金组织特别提款权 `XDR`；
- 部分离岸货币和地区性记账单位。

这些条目共用同一换算列表，但它们的市场报价、交易时间和实际可兑换性可能与法定货币不同。

## 管理货币卡片

### 添加货币卡片

1. 滚动到主列表底部。
2. 点击“添加货币”。
3. 在自动打开的选择窗口中选择目标货币。

<ThemeImage
  src="/images/docs/exchange/currencies/add-currency.png"
  alt="汇率列表底部的添加货币按钮和新打开的货币选择窗口"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

新卡片会先以美元创建。如果没有完成选择便关闭窗口，美元卡片仍会保留，可以稍后点击代码重新选择。

### 调整卡片顺序

长按一张货币卡片，待卡片浮起后上下拖动到目标位置，再松开手指。最终顺序会保存在设备本地。

<ThemeImage
  src="/images/docs/exchange/currencies/reorder-currencies.png"
  alt="长按拖动一张货币卡片并调整它在换算列表中的位置"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

排序只改变显示顺序，不会改变当前汇率或换算结果。

### 删除货币卡片

1. 在目标卡片上向左滑动。
2. 点击出现的红色垃圾桶按钮。
3. 卡片会立即从列表中移除。

<ThemeImage
  src="/images/docs/exchange/currencies/delete-currency.png"
  alt="汇率卡片左滑后显示红色垃圾桶删除按钮"
  style={{ maxWidth: '240px', height: 'auto', borderRadius: '12px', marginTop: '16px' }}
/>

删除没有单独的确认对话框。如果删除的是当前输入货币，CalculatorX 会把列表中的第一张卡片设为新的输入货币，并把输入金额重置为 `0`。

建议至少保留两张卡片，否则页面无法形成有意义的货币换算。误删后可以通过“添加货币”重新加入。

## 保存规则

以下内容会保存在设备本地：

- 货币卡片及其顺序；
- 当前输入货币；
- 最近输入的金额。

汇率模式不使用计算历史。需要重复使用某组货币时，直接保留并排序对应卡片即可。
