# CalculatorX 使用手册

CalculatorX 是一款面向 HarmonyOS 的科学与符号计算器。你可以用它完成日常计算，也可以处理科学函数、方程、矩阵、函数图像和汇率换算。

如果你是第一次使用 CalculatorX，可以先跟随本页完成一次基础计算，再按需要阅读后续专题。

## 认识主界面

计算页面从上到下分为顶栏、公式显示区和按键区。顶栏用于打开侧边栏、识别当前模式以及进入该模式支持的历史记录或编辑功能；公式显示区负责输入和展示结果；按键区会随模式改变。

不同模式共用相似的界面结构，但顶栏按钮和键盘会根据当前任务变化。例如，科学计算、方程求解和矩阵模式提供撤销与重做；函数图像模式的右上角则是编辑按钮。

## 完成第一次计算

下面以 $12+8\times3$ 为例：

1. 点击左上角的侧边栏按钮。
2. 在“模式”分组中选择“基础计算”。
3. 依次点击 <kbd className="key-cap">1</kbd>、<kbd className="key-cap">2</kbd>、<kbd className="key-cap">+</kbd>、<kbd className="key-cap">8</kbd>、<kbd className="key-cap">×</kbd>、<kbd className="key-cap">3</kbd>。
4. 检查公式显示区中的表达式是否为 $12+8\times3$。
5. 点击 <kbd className="key-cap">=</kbd>，结果应为 $36$。

CalculatorX 会按照通常的数学运算顺序先算乘除、后算加减，因此上例先计算 $8\times3$，再与 $12$ 相加。

## 选择适合的模式

侧边栏提供当前版本已经开放的主要功能：

| 模式 | 适合完成的任务 |
| --- | --- |
| 基础计算 | 四则运算、百分数和小数计算 |
| 科学计算 | 三角函数、指数对数、代数和微积分 |
| 方程求解 | 一元方程和多元方程组 |
| 矩阵与向量 | 矩阵输入及线性代数运算 |
| 函数图像 | 绘制和比较不同类型的函数 |
| 汇率 | 多币种金额换算和离线缓存 |

切换模式不会改变全局设置。主题、角度单位、答案格式和触感反馈等偏好会继续生效。

## 接下来去哪儿？

如果你已经完成第一次计算，可以按当前任务选择入口。首页只保留每组内容的主要入口，更详细的教程可以从侧边栏或各专题页继续阅读。
